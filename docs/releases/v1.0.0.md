## 新功能

- 设置底部新增「版本与更新」：显示当前版本、最近检查结果和时间，可手动检查并打开发行页下载新版。
- 每次启动检查一次 GitHub 正式版，随后每 15 分钟检查一次。面板隐藏到托盘时仍有效，同一新版每次运行最多提醒一次；不会自动安装或重启。

## 改进

- 提供 Windows x64 当前用户安装包、便携 ZIP 和 SHA-256 校验清单。界面、程序文件和安装包使用同一版本号。

## 修复

- 设置了起始时间的固定间隔提醒，重启或重新启用后仍沿用原定节奏。例如从 11:58 起每 30 分钟执行，16:26 打开时下次为 16:28。离线期间不补发、不扣减次数。

## 安装与升级

先右键系统托盘中的 Lynx Notify 选择「退出」，再运行 **LynxNotify.Setup.1.0.0.exe**，或将 **LynxNotify-1.0.0.zip** 完整解压到新目录。两种方式都会沿用当前用户已有的任务和设置。安装包未签名，Windows 可能提示未知发布者；请从本 Release 下载并对照 **SHA256SUMS.txt** 核验。
