# 架构决策

## 标题栏静态图标使用 Lynx `image`

- 日期：2026-08-20
- 状态：采用
- 背景：当前 LynxSDK 4.0 Windows 预编译核心未注册独立 `svg` 模板视图，直接使用 `<svg>` 会显示为空白。
- 决策：SVG 继续作为设计源；运行时资源使用透明 PNG，并由核心内建 `<image>` 渲染。
- 理由：无需修改或自行编译 LynxSDK，不引入字体字形兼容问题，且已经通过 Windows 原生视觉和交互验证。
- 边界：如果未来需要动态矢量内容、动画或运行时改色，再单独评估 Windows SVG XElement 的自定义注册与维护成本。
